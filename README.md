В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Проект представляет собой планировщик задач c GUI, реализованной через web сервис, и базой данной sqlite.

##Задания со звездочкой
Поддерживаются: 
    - функционал смены TCP порта, через которое доступен web сервис приложения [x]
    - возможность задать имя базы данных [x]
    - задания с флагом еженедельным или ежемесячным повторением [ ]
    - поиск заданий по тексту [ ]
    - аутентификаци/авторизация [ ]

##Запуск
Без сборки бинарного файла запуск приложения осуществляется следующим способом:
```TODO_PORT=%port% TODO_DBFILE=%dbfile% go run *.go```
| Параметр | Значение по умолчанию | Константа в main.go |
| :------- | :-------------------- | :------------------ |
| TCP port | 7540                  | webPortDefault      |
| DB file  | scheduler.db          | dbNameDefault       |


##Тесты
1. ```go test -run ^TestApp$ ./tests``` - Тест запуска WEB сервиса и доступности файлов фронта
2. ```go test -run ^TestDB$ ./tests``` - Тест доступности базы данных и наличия в ней таблицы заданий
3. ```go test -run ^TestNextDate$ ./tests``` - Тест доступности **/api/nextdate** и корректности работы алгоритма поиска следующей даты выполнения для периодических задач
4. ```go test -run ^TestAddTask$ ./tests``` - Тест добавления и получения задачи **/api/task**
5. ```go test -run ^TestTasks$ ./tests``` - Тест получения списка задач **/api/tasks**
6. ```go test -run ^TestEditTask$ ./tests``` - Тест редактирования задачи **/api/tasks**
7. ```go test -run ^TestDone$ ./tests``` - Тест функционала завершения задач **/api/task/done**
8. ```go test -run ^TestDelTask$ ./tests``` - Тест функционала удаления задач **/api/task**
9. ```go test ./tests``` - Запуск всех тестов сразу
